# 页面跳转扩展

在 Chrome 或 Edge 的扩展管理页面启用“开发者模式”，选择“加载已解压的扩展程序”，并选择本目录。加载或更新扩展后刷新 AI 助手页面。

扩展仅支持清单中配置的助手地址，以及 `background.js` 中的内部系统地址。地址变化时，需要同步修改 `manifest.json`、`bridge.js` 和 `background.js`，然后重新加载扩展。扩展通过内部系统同源的 `/detection-api/api/v1/me/access` 接口获取当前用户菜单；如果系统的接口前缀变化，也需要更新 `background.js`。

跳转需要登录时，请在内部系统页面手动登录；扩展不会读取或保存密码。扩展使用系统浏览器会话查询菜单权限，不会将令牌传给 AI 助手。浏览器未安装扩展时，助手保留手动打开的链接。
